# Household Chores Manager — v1 Spec

## Context
Small household with vegetable garden and cat. Tool to manage shared chores.

## Problem
Remembering recurring tasks (watering, litter, house basics).

## Scope (v1 — 3 features)
1. **Chores with custom repeat** — house + cat + garden basics, custom intervals (e.g. every 3 days), due dates.
2. **Kanban board** — columns: To do / Today / This week / Doing / Done.
3. **Manual assign + overdue highlight** — assign manually, overdue visually highlighted. Email/push deferred to later.

## Out of scope for v1
- Email / push notifications
- Auto-rotation
- Full garden schedule

## Decisions from brainstorm
- Who: small household
- Pain: A) Remember recurring tasks
- Areas: A) house + cat + garden basics
- Assign: C) manually
- Recurrence: B) custom intervals
- Board: Kanban To do / Today / This week / Doing / Done
- Reminders: overdue highlight only for v1
